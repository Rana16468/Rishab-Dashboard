# Rishab Dashboard

Simple admin dashboard built with **Next.js** (App Router) and **React**. This repo contains an admin panel for user management, chat history, and analytics.

---

## Features

- Admin authentication and role-based access
- User list with search and pagination
- Conversation history modal with export/delete options
- Responsive layout and reusable UI components
- Uses Tailwind CSS and Lucide icons

---

## Tech Stack

- **Next.js** (App Router)
- **React 19**
- **TypeScript**
- **Tailwind CSS**
- **Redux Toolkit** for state management
- **Radix UI** primitives for base components

---

## Getting Started

1. Clone the repo:
   `ash
   git clone https://github.com/Ahteshamull/Rishab-Dashboard.git
   cd Rishab-Dashboard
   `
2. Install dependencies:
   `ash
   pnpm install # or npm install
   `
3. Run dev server:
   `ash
   pnpm dev # or npm run dev
   `
4. Open http://localhost:3000 in your browser.
